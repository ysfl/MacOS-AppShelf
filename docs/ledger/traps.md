# 坑位与防线台账

一行一个坑。入册标准：已经实际踩过，且形态上可能再次出现。一次性、没有复发路径的缺陷
记进提交说明就够，不进这里。

每行的「防线」列必须写一个**存在的测试函数名**。`Scripts/gates/gates.py` 的
`traps-ledger` 检查会拿它去比对 `Tests/` 里的实际函数，指不到测试的行会被判为错误——
一条没有防线的记录只是提醒，提醒会烂掉。

## 尚未升格为门禁脚本的项

T-001、T-008、T-010、T-012 属于运行时行为或视觉结果，静态检查判不了。它们靠
`Scripts/visual-check.sh` 出图 + 人工确认，发布前必须跑一次。该脚本已在 1.4.0 之后
首次完整执行，产出 9 组外观×语言 + 搜索键盘态 + 设置面板共 11 张图。
